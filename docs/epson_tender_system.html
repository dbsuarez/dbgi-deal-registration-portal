📖 System Instructions & Guidelines

Getting Started

Follow these steps to submit a tender form:

  1. Fill Dealer Profile: Enter your company details and contact information
  2. Enter End-User Information: Provide complete customer company details
  3. Project Details: Most importantly, enter your OPPORTUNITY ID (required!)
  4. Select Epson Models: Add one or more Epson products with quantities
  5. Complete Project Profile: Fill in all required fields marked with asterisk (*)
  6. Competitor Info (Optional): Add competitor details if relevant
  7. Set Schedule: Enter all important dates
  8. Submit: Click "Submit Form" button
Important Reminders
  • ❌ NO OPPORTUNITY ID = Form Rejected - Always get your opportunity ID from Epson Account Manager
  • 🔵 ALL BLUE SHADED FIELDS must be completely filled out
  • ⏰ Processing Time: 3-5 days for local, 5-7 days for regional approvals
  • 📄 Government Bids: Must include supporting bid documents
  • 📅 Tender Validity: Valid for 60 days only - submit new form if expired
  • 📊 Quantities Monitored: System tracks registered quantities for pricing compliance
